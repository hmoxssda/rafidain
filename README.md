# عربي كود (Arabi Code)

Arabi Code هي لغة برمجة تجريبية تعتمد على بناء جملة عربي بالكامل مع دعم لمعظم ميزات بايثون الأساسية. يتكون تنفيذ اللغة من محلل لفظي، ومحلل نحوي، ومفسر، ومترجم إلى بايثون مكتوبة جميعها بلغة Python 3.

## المتطلبات

- Python 3.10 أو أحدث.
- لا توجد تبعيات إضافية؛ جميع المكونات مكتوبة باستخدام مكتبة Python القياسية.

## التثبيت والاستخدام

1. استنسخ المستودع أو نزّل الملفات.
2. فعّل بيئة Python اختيارياً.
3. نفّذ الأمثلة أو شغّل برامجك عبر المفسر.

### تشغيل برنامج عربي كود

```bash
python - <<'PY'
from interpreter import ArabicInterpreter

interpreter = ArabicInterpreter()
interpreter.run_file("examples/hello.arb")
PY
```

يمكنك أيضاً تمرير النص مباشرة:

```python
from interpreter import ArabicInterpreter

الكود = """
متغير عدد = 10
إذا (عدد > 5) {
    اطبع("عدد كبير")
}
"""

ArabicInterpreter().execute(الكود)
```

### استخدام المترجم لتحويل الكود إلى Python

```python
from compiler import ArabicCompiler

compiler = ArabicCompiler()
python_source = compiler.compile_file("examples/hello.arb")
print(python_source)
```

## البنية العامة للغة

| الميزة            | الصياغة في عربي كود                      | المكافئ في Python            |
|-------------------|-------------------------------------------|------------------------------|
| المتغيرات         | `متغير x = 5`                             | `x = 5`                      |
| الدوال            | `دالة جمع(a, b) { رجع a + b }`           | `def جمع(a, b): return a + b`|
| الشرطيات          | `إذا (شرط) { ... } وإلا { ... }`          | `if condition: ... else: ...`|
| حلقات while       | `كرر (شرط) { ... }` أو `بينما (شرط) {}`  | `while condition:`           |
| حلقات for         | `كرر (i = 0; i < n; i++) { ... }`        | `for i in range(0, n): ...`  |
| الطباعة           | `اطبع("نص")`                            | `print("نص")`               |
| القيم المنطقية    | `صح` و `خطأ`                             | `True` و `False`             |
| عدم القيمة        | `لا شيء`                                 | `None`                       |
| الكائنات          | `كائن شخص { هذا.الاسم = "أحمد" }`      | `class شخص: def __init__(self): self.الاسم = "أحمد"` |
| الاستيراد         | `استورد الرياضيات`                       | `import math`                |

### ملاحظات حول الحلقات

- حلقات `كرر` ذات الصيغة C (`متغير i = 0; i < 10; i++`) تُحوَّل تلقائياً إلى `range` في بايثون بشرط أن يكون تحديث العداد خطوة بمقدار 1 أو -1.
- عند الحاجة إلى صيغ أكثر تعقيداً يمكن استخدام `كرر (شرط)` والتي تتحول مباشرة إلى حلقة `while`، مع كتابة التهيئة وتحديث العداد داخل الكتلة يدوياً.

### تعريف الكائنات

يحوّل التعريف `كائن` إلى صنف Python مع منشئ افتراضي (`__init__`) يملأ الحقول باستخدام `هذا.` كمكافئ لـ `self.`. بعد التعريف يمكن إنشاء الكائن عن طريق استدعاء اسم الصنف:

```arabi
كائن شخص {
    هذا.الاسم = "أحمد"
    هذا.العمر = 30
}

متغير فرد = شخص()
```

## التعامل مع اللغة العربية

- تتم إزالة التشكيل تلقائياً أثناء التحليل، لذا فإن كتابة `مُتَغَيِّر` أو `متغير` يعطي نفس النتيجة.
- يمكن استخدام أحرف عربية أو لاتينية في أسماء المتغيرات والدوال.
- يتم تحويل بعض الكلمات المفتاحية الشائعة تلقائياً: `و`, `أو`, `ليس` إلى `and`, `or`, `not`.

## تطوير وتوسعة

- يمكن تخصيص خريطة الاستيراد في `ArabicParser` لربط أسماء مكتبات عربية بوحدات Python إضافية.
- لمعالجة أخطاء الصياغة ستظهر رسائل `SyntaxError` مع وصف عربي عند عدم القدرة على تحويل كتل معينة (مثل حلقات `كرر` غير المدعومة).

## اختبارات سريعة

لتجربة المكونات الأساسية:

```bash
python - <<'PY'
from lexer import ArabicLexer
from parser import ArabicParser
from interpreter import ArabicInterpreter

source = open('examples/hello.arb', encoding='utf-8').read()

# 1) التحقق من المخرجات اللفظية
lexer = ArabicLexer()
tokens = lexer.tokenize(source)
print('عدد التوكنات:', len(tokens))

# 2) ترجمة إلى Python
parser = ArabicParser()
print(parser.translate_to_python(source))

# 3) التنفيذ
ArabicInterpreter(parser).execute(source)
PY
```

سيتم طباعة البرنامج باللغة العربية ثم تنفيذه بواسطة Python.

## الأمثلة

يوجد مجلد `examples/` يحتوي على أمثلة قابلة للتشغيل تغطي المتغيرات، الحلقات، الدوال، تعريف الكائنات، والاستيراد. يمكن تعديلها أو إنشاء ملفات جديدة بالامتداد `.arb`.

التنفيذ الحالي مصمم كبداية تعليمية. يمكن إضافة دعم لبناء جملة إضافي (مثل معالجة قوائم الاستيراد، الاستثناءات، أو الأنواع المتقدمة) من خلال توسيع المحلل النحوي والمفسر.
